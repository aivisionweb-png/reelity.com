# REELITY

**Your life. One scene at a time.**

A cinematic AI entertainment MVP: upload an ordinary photo, choose a genre, and turn the moment into a movie scene.

## Current MVP

- Mobile-first cinematic interface
- Drag/drop or device photo upload
- Action / Horror / Bollywood / Thriller / Comedy / Sci-Fi genres
- Animated generation flow
- Automatic cinematic title + scene description
- Result/movie-card experience
- Share button
- No login required
- No external backend required for the demo

## Run

Open `index.html` directly, or deploy the folder to Vercel/Netlify/GitHub Pages.

## Next step: real AI video

Replace the mock generation flow in `script.js` with a server-side API endpoint that sends the uploaded image + generated scene prompt to an image-to-video provider.

Do NOT put private API keys in `script.js` or any browser-side file. Use a serverless/backend endpoint and environment variables.
